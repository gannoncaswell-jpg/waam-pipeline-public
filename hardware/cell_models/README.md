# Cell geometry

Generate the model with `python hardware/cell_models/cell_models.py` and the calibration worksheet with `python hardware/cell_models/gen_measurement_sheet.py`.

Measurement rows to verify before using the cell: `axis-above-robot-base`, `cell-base-structure`, `cell-frame-fore-aft`, `cell-frame-lateral`, `disconnect-envelope`, `equipment-rack-registration`, `faceplate-plane-lateral`, `feeder-arm-station`, `feeder-bracket-offset`, `frame-envelope-datums`, `mh185-stand-splice-z`, `pedestal-connections`, `platter-face-row`, `platter-hole-x`, `reamer-stand-position`, `spool-housing-support`, `spool-mount-offset`, `station-axis-forward`, `station-handedness`, `waam-fixture-registration`, `wire-conduit-routing`.
