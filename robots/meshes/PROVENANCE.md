# Robot mesh sources

Meshes and reference xacros are from https://github.com/ros-industrial/motoman at commit `846fbbc57c60223f12bf4795ea6404982d57709e`, packages `motoman_gp12_support` and `motoman_hc10_support`, declared BSD-3-Clause.

Original upstream package attribution and license declarations are retained in `licenses/`.

AR1440 visuals use the GP12 platform meshes. HC10DTP-B00 uses the HC10 meshes with its variant wrist. Display meshes are derived from those sources; collision geometry and calibration are separate.
